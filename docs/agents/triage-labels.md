# Local Triage Labels

This repository tracks work as local Markdown under `.scratch/`. The labels below are written as issue metadata or comments; they do not create remote labels.

| Role              | Label             | Meaning                                                                                 |
| ----------------- | ----------------- | --------------------------------------------------------------------------------------- |
| Needs triage      | `needs-triage`    | An incoming report has not yet been classified.                                         |
| Needs information | `needs-info`      | Work cannot proceed until a material fact or user decision is supplied.                 |
| Ready for agent   | `ready-for-agent` | Scope, acceptance criteria, and evidence are sufficient for an agent to claim the work. |
| Ready for human   | `ready-for-human` | The task needs a product, policy, or approval decision that an agent must not assume.   |
| Will not fix      | `wontfix`         | The request is intentionally not planned, with its reason recorded in the issue.        |

Use only these canonical label strings unless the project owner changes this file.
