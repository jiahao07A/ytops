# 01 — 安全配置与配置合同

**Type:** task

**What to build:** 让频道运营者能够初始化、校验和理解全局运行配置、单频道同步配置与分析配置档案，同时保证配置不承载任何受保护凭据。

**Blocked by:** None — can start immediately.

**Status:** resolved

**Labels:** ready-for-agent

- [x] 用户可以初始化三层配置，并获得对每个选项的可读说明。
- [x] 用户可以校验配置并得到明确、可操作的错误信息。
- [x] 用户可以用命令临时覆盖允许覆盖的选项，或将其保存为持久配置。
- [x] 令牌、客户端秘密和其他受保护凭据被拒绝写入配置，也不会出现在校验输出中。

## Answer

已实现不承载凭据的三层配置合同：`config init`、`validate`、`explain`、`set-global`、`set-channel` 和 `set-profile` 均提供稳定 JSON 输出。持久化更新以跨进程锁和同目录原子替换保护；配置校验、可执行说明、凭据拒绝和并发更新均有回归覆盖。
