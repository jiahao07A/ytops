# 10 — 频道运营配置辅助 skill

Type: task

What to build: 提供一个随仓库版本化的配置辅助 skill，使 AI 能理解宽泛中文表达并安全地指导用户初始化、校验、解释和修复频道运营数据配置。

Blocked by: 01 — 安全配置与配置合同.

Status: resolved

- [x] skill 能处理初始化频道接入、生成分析配置、检查并解释配置、修复校验错误等宽泛表达。
- [x] skill 先读取现状、提出可见配置差异、征得确认后才写入，并在写入后执行配置校验。
- [x] skill 指导 OAuth 的前置配置和授权步骤，但不接触、回显或保存秘密，也不代为启动授权或同步。
- [x] skill 经过结构校验，并以真实配置场景验证其指导可执行且不越权。

## Answer

已交付频道运营配置辅助协议，并由主 skill 链接到版本化参考文件。协议覆盖频道接入初始化、分析配置档案、配置检查/解释和校验错误修复；统一要求先读取现状、展示变更前后差异、取得用户明确确认后才调用 `config set-*`，写入后立即执行 `config validate`。OAuth 仅提供 Google Cloud、同意屏幕、回调地址和授权步骤指引，不要求或保存客户端秘密、授权码或令牌，也不代用户执行授权或同步。

验证：`test/skills-contract.test.ts` 通过（1 个测试文件、10 项测试）；使用临时配置执行 `config init` 与 `config validate` 的 CLI/JSON 场景通过，且未在未确认流程中调用任何持久化覆盖命令。
