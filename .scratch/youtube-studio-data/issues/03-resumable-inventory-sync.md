# 03 — 可恢复的基础数据仓库同步

**Type:** task

**What to build:** 让一个已建立频道接入的运营者将频道、视频和上传播放列表元数据同步到本机运营数据仓库，并能观察和恢复中断的同步。

**Blocked by:** 02 — OAuth 授权与显式频道接入.

**Status:** open

**Labels:** ready-for-agent

- [ ] 用户可以为已选择频道开始或按配置安排基础数据同步，并在本机查询到规范化的频道、视频和上传播放列表数据。
- [ ] 每个同步范围保存原始证据、来源、获取时间和可恢复检查点，但不保存凭据。
- [ ] 分页、网络中断或进程中止后，用户可从检查点续传，不会把已确认数据误报为未完成或重复数据。
- [ ] CLI/JSON 可显示同步进度、最后成功时间、失败原因和数据截至时间。
- [ ] 用户可通过持久化配置或本次 CLI 参数选择基础元数据同步范围（频道、视频、上传播放列表），并在状态和检查点中记录实际范围。
- [ ] 规范化数据默认不自动删除；原始证据遵循全局或频道保留期，任何清理都要求明确频道和数据范围。
- [ ] 本机仓库仅通过窄的官方 API 适配层获取数据，CLI 事实合同不依赖具体 API 客户端实现。
