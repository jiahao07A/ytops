# 01: 核心同步双口径与新互动指标

Type: task
Status: open
Label: ready-for-agent
Blocked by: none

**What to build:** 频道运营者执行一次核心运营数据同步后，运营数据仓库同时保存播放口径与互动口径的观看序列（ADR 0002），以及不喜欢、新增订阅、流失订阅三个互动指标，频道级×日与视频级×日两阶段皆然；既有状态、事实查询与新鲜度命令无需额外操作即可读到新指标；改版生效日之前的历史行保持原口径、不改算。实现前置一步预重构：把指标白名单的分散登记收敛为单一事实源，然后再扩展，避免双份清单漂移。

- [ ] 同步完成后，频道级与视频级数据同时包含两种观看口径与三个新增互动指标，且两种口径来自同一请求
- [ ] 改版生效日之前的历史行保持原口径，无任何改算
- [ ] 不需要任何新权限即可同步上述指标（均在分析只读权限内）
- [ ] 指标白名单为单一事实源，配置校验与说明登记与之保持一致
- [ ] 回填深度语义不变：默认 365 天、命令行可调、上限 3650 天
- [ ] 库层测试覆盖双口径并存、同请求获取、白名单外指标拒绝；CLI 测试覆盖状态/查询/读取输出
- [ ] README 与 skills 入口字符串合同、面向用户简体中文元数据门禁通过；全量校验（verify）通过
