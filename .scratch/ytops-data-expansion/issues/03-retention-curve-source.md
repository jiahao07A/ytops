# 03: 留存曲线数据源（同步 + 按需查询）

Type: task
Status: open
Label: ready-for-agent
Blocked by: none

**What to build:** 新增留存曲线只读数据源。运营者执行留存同步时，首次对库存全部视频建立全历史留存曲线（按视频清单分页推进、断点续传，复用既有同步任务的检查点模式），后续每轮只处理新发现的视频；留存曲线为单视频全历史、固定比例横轴约一百个点、数值可超过 1 并如实呈现。另有按需事实查询命令返回单个视频的留存曲线（支持最后可用数据与强制最新查询语义），以及状态命令查看同步进度。

- [ ] 首次留存同步处理库存全部视频；中断后从检查点恢复，不重复拉取已完成视频
- [ ] 后续同步只请求新发现的视频
- [ ] 按需命令返回单视频全历史曲线，超过 100% 的点如实呈现
- [ ] 强制最新查询在源站刷新失败时返回失败，而不使用过期数据
- [ ] 原始证据落盘且不含凭据样文本；隐私阈值单元格省略而非置零
- [ ] 覆盖矩阵新增留存曲线能力条目并正确映射状态
- [ ] 库层测试覆盖断点续传、增量与曲线解析；CLI 测试覆盖同步/状态/读取三件套；文档合同与中文门禁通过；verify 通过
