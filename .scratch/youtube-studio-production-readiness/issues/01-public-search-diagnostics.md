# 01: 公开检索与外部工具诊断合同

Type: task
Status: claimed
Blocked by: None (can start immediately)

## What to build

让频道运营者能够通过健康检查明确判断 `yt-dlp` 是否可执行，并从构建后的 CLI 稳定完成公开内容搜索、单视频详情和字幕可用性查询。外部工具故障和响应损坏必须返回可操作且互不混淆的 JSON 错误。

## Acceptance criteria

- [ ] 健康检查区分可执行文件不存在、无执行权限、程序损坏或无法启动、外部进程非零退出和输出无法解析。
- [ ] 搜索、详情和字幕命令均从构建后的 CLI 返回单个稳定 JSON，并保持只读、不下载媒体、不读取浏览器 Cookie。
- [ ] CLI 和公共检索边界共享非空搜索词与 1-50 数量校验，非法输入在启动外部进程前失败。
- [ ] 合法空搜索结果与缺少必要结构、畸形 JSON 或异常条目得到不同结果，损坏响应不得静默伪装为空列表。
- [ ] 自动测试通过可控的伪 `yt-dlp` 可执行程序覆盖成功、空结果和全部错误分类，不依赖当前机器的真实安装状态。
- [ ] JSON、标准错误和诊断详情不包含 Cookie、凭据或用户级 `yt-dlp` 配置内容。
