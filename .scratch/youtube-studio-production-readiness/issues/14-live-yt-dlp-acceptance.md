Type: task
Status: open
Labels: ready-for-human
Blocked by: 01 公开检索与外部工具诊断合同

## What to build

在真实 Windows 环境中解除当前 `yt-dlp` 执行阻塞，并用公开、非敏感输入验证健康检查、搜索、详情和字幕查询确实可运行。验收记录只保留脱敏命令、退出码和结构摘要。

## Acceptance criteria

- [ ] 用户确认可以检查或修复本机 `yt-dlp` 安装及执行权限，未经批准不变更系统安装。
- [ ] 健康检查将真实环境识别为可用；若仍失败，准确的错误分类和修复建议与实际原因一致。
- [ ] 使用公开搜索词完成一次真实搜索，并验证返回数量边界和必要 JSON 字段。
- [ ] 使用公开视频完成详情和字幕可用性查询，不下载媒体或读取浏览器 Cookie。
- [ ] 记录实际命令、退出码、错误类别和结构摘要，不保存 Cookie、个人数据或大段平台响应。
- [ ] 当前机器仍为 `Access is denied` 时票据保持 open，不以离线替身结果代替真实验收。
