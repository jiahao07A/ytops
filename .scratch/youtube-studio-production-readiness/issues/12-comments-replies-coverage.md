# 12: 评论线程、回复与部分覆盖

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 06 跨进程互斥与有界并发

## What to build

让频道运营者持续同步评论线程和可授权读取的全部回复，并在权限、配额或官方能力无法补齐回复时得到准确的部分覆盖状态和原因。

## Acceptance criteria

- [ ] 官方 Data API provider 完整遍历评论线程分页，并对需要补齐的线程遍历回复分页。
- [ ] 线程和回复使用稳定身份去重，重复同步和检查点恢复不产生重复记录。
- [ ] 空频道、删除评论、关闭评论、权限不足和配额耗尽分别映射为准确状态。
- [ ] 只有无法完整获取回复时才返回 `partial`，并包含未覆盖原因、数据截至时间和证据引用。
- [ ] 评论同步接入统一任务身份、到期调度、配额预算和跨进程互斥合同。
- [ ] 失败或部分完成不会以空列表掩盖已保存的最后可用评论数据。
- [ ] CLI 测试覆盖线程与回复多页、检查点、重复数据、空结果、权限和部分覆盖。
