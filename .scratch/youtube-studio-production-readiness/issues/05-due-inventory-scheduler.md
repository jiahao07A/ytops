# 05: 运行所有到期 Inventory 任务

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 02 OAuth 持久续期生命周期; 04 以 Inventory 贯通统一同步任务合同

## What to build

让频道运营者通过一次性调度命令运行所有已经到期的 Inventory 同步任务，使首次回填、日常增量、漏跑补偿、退避和配额预算在不启动常驻守护进程的前提下可靠推进。

## Acceptance criteria

- [ ] `ops channel scheduler run` 作为稳定 JSON 命令执行一次到期任务周期，结束后不留下自制常驻进程。
- [ ] 调度使用持久化时间和可注入时钟判断首次运行、正常频率、漏跑补偿和重试退避。
- [ ] 未到期任务不会发起外部请求；到期任务从既有检查点继续，而不是默认重新全量同步。
- [ ] 频道配额预算在任务启动和每次翻页前检查；预算不足时保存检查点并进入可恢复状态。
- [ ] 单个任务失败不会阻止其他到期任务被观察和处理，周期结果汇总每个任务的结构化状态。
- [ ] 进程重启后再次运行会基于持久化状态继续，重复执行不会重复确认过的事实。
- [ ] 自动测试通过伪时钟和伪 provider 验证上述行为，不使用真实等待或真实账号。
