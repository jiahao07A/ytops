# 11: Reporting CSV 与持续日报导入

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 10 Reporting 官方任务与报告发现生命周期

## What to build

让已经就绪的 Reporting 日报通过成熟 CSV 解析器可靠、幂等地进入运营数据仓库，并让调度从等待状态继续到导入后仍能发现下一份日报。

## Acceptance criteria

- [ ] 使用成熟的流式 CSV 解析器处理标准引号、逗号、嵌入换行、空值和大文件，不保留手写通用 CSV 状态机。
- [ ] 每行使用稳定身份幂等导入；同一报告重复执行不会产生重复事实。
- [ ] 原始报告、请求条件、下载元数据和规范化事实分开保存，并保持脱敏证据引用。
- [ ] 进程在下载或导入中断后可以恢复，不把不完整文件或未提交批次标记为已导入。
- [ ] 调度能够把 `waiting` 任务推进到下载和导入；导入完成后继续按下一次报告时间安排检查。
- [ ] 不同报告类型和生成周期不会共享行身份或覆盖彼此的数据。
- [ ] fixture 测试覆盖引号、分隔符、嵌入换行、空值、重复行、重启恢复和后续日报发现。
