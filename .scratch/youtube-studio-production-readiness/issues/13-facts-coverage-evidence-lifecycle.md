# 13: 事实查询、覆盖矩阵与证据生命周期

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 08 核心 Analytics 可信同步; 09 高维 Analytics 档案可信同步; 11 Reporting CSV 与持续日报导入; 12 评论线程、回复与部分覆盖

## What to build

让频道运营者从所有事实查询一致地判断数据截至时间、覆盖状态和最近刷新结果，能够定位脱敏原始证据，并让原始证据保留期实际生效而不删除长期规范化事实。

## Acceptance criteria

- [ ] Inventory、核心与高维 Analytics、Reporting 和评论查询统一返回数据截至时间、覆盖状态和最近刷新尝试。
- [ ] 覆盖矩阵取自各数据源的实际任务和资格状态，不把 waiting、partial、权限不足或合法空结果错误标为已完整支持。
- [ ] 每项事实可以定位请求条件、获取时间、来源标识和脱敏原始证据，且不会暴露受保护凭据。
- [ ] 普通查询与强制最新查询在所有数据源上保持一致的新鲜度和失败语义。
- [ ] 到期任务周期按频道接入和数据源范围执行原始证据保留期，只清理明确到期的原始证据。
- [ ] 规范化数据和范围外证据不会被自动删除；清理重复执行幂等并返回可核验摘要。
- [ ] 旧覆盖和证据状态通过兼容迁移继续可读，跨源 CLI 合同测试验证查询、复查和清理的完整路径。
