# 09: 高维 Analytics 档案可信同步

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 03 最小授权与货币数据权限; 08 核心 Analytics 可信同步

## What to build

让频道运营者能够按分析配置档案持续同步完整的流量来源、设备、地域、受众或收入等高维细分数据，并确保每个查询身份、权限和分页范围互不污染。

## Acceptance criteria

- [ ] 高维查询消费所有分页，超过单页上限时不会静默截断。
- [ ] 任务身份包含频道、日期窗口、指标、维度、筛选和分析配置档案；任一条件改变都产生隔离状态。
- [ ] 指标、维度和筛选组合在访问源站前校验，不支持组合返回明确输入或资格限制。
- [ ] 收入查询只有在显式货币 scope 可用时执行，缺少权限时不返回零值或空成功。
- [ ] 高维任务接入到期调度、配额预算、检查点和跨进程互斥合同。
- [ ] 重复运行幂等更新同一查询身份，并保留其他身份的历史事实。
- [ ] CLI 和 provider 合同测试覆盖多页、空结果、权限不足、档案隔离和数据截至时间。
