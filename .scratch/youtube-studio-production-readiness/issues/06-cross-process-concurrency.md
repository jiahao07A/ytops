# 06: 跨进程互斥与有界并发

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 05 运行所有到期 Inventory 任务

## What to build

让多个 CLI 进程同时运行调度或手动同步时保持运营数据仓库一致：同一同步任务只能有一个执行者，不同任务可以在配置上限内并发，崩溃后的锁能够恢复。

## Acceptance criteria

- [ ] 同一频道接入、数据源和同步范围在跨进程层面最多只有一个执行者。
- [ ] 第二个竞争进程返回明确的忙碌、延期或可重试状态，不覆盖正在运行的任务数据。
- [ ] 不同任务使用成熟并发限制依赖运行，实际并发数不超过配置上限。
- [ ] 状态、规范化数据、检查点和凭据继续采用原子写入，锁只覆盖必要的任务边界。
- [ ] 进程异常终止后锁可以安全恢复，后续运行不会把未确认页标记为完成。
- [ ] 自动测试并行启动构建后的真实 CLI 子进程，验证排它、并发上限、崩溃恢复和文件完整性。
