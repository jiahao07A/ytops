# 08: 核心 Analytics 可信同步

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 06 跨进程互斥与有界并发

## What to build

让频道运营者通过手动命令或到期调度获得完整、窗口隔离且新鲜度语义准确的频道和视频级核心 Analytics 事实。

## Acceptance criteria

- [ ] 官方 Analytics provider 从 1-based 起始索引开始并消费全部后续页。
- [ ] 响应缺少 `rows` 或包含空 `rows` 时成为成功的空事实集，缺失指标保持缺失而不转换为零。
- [ ] 任务身份隔离频道、日期窗口和查询口径；新窗口不会混入旧窗口行，旧事实仍可按原身份读取。
- [ ] 网络、配额、权限和部分覆盖使用统一任务状态，逐页请求遵守配额预算和检查点。
- [ ] 普通读取在刷新失败时可以返回明确标记为过期的最后可用数据；强制最新查询失败且不回退。
- [ ] 核心 Analytics 注册为到期任务，可在调度、重启和并发环境中幂等恢复。
- [ ] 构建后 CLI 测试覆盖分页、合法空结果、窗口隔离、回退和强制最新合同。
