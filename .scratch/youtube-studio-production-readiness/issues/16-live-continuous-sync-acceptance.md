# 16: 真实持续同步与系统调度验收

Type: task
Status: open
Labels: ready-for-human
Blocked by: 07 显式管理 Windows 定期任务; 13 事实查询、覆盖矩阵与证据生命周期; 15 真实 OAuth、DPAPI 与官方 API 冒烟验收

## What to build

在用户明确批准系统任务变更后，用测试频道验证两轮真实增量同步、漏跑补偿、令牌续期、进程重启和事实查询闭环。长时间 Reporting 生成与导入由 17、18 单独验收。

## Acceptance criteria

- [ ] 安装前向用户展示 Windows 系统任务名称、命令、频率和影响，并取得明确批准。
- [ ] 系统任务安装、状态查询和停用与 CLI JSON 合同一致，不保存凭据到系统任务定义。
- [ ] 测试频道完成两轮 Inventory、核心与高维 Analytics 以及评论增量同步，第二轮不重复已确认事实。
- [ ] 至少验证一次进程重启或漏跑后的补偿，以及一次过期访问令牌的自动续期。
- [ ] 同步期间任务状态、并发上限、配额处理和失败恢复与本地状态一致。
- [ ] 事实查询在每轮后显示正确的数据截至时间、覆盖状态、刷新结果和脱敏证据引用。
- [ ] 验收记录不包含真实频道内容、凭据或原始 API 响应。
