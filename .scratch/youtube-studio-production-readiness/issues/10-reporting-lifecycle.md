# 10: Reporting 官方任务与报告发现生命周期

Type: task
Status: open
Labels: ready-for-agent
Blocked by: 06 跨进程互斥与有界并发

## What to build

让频道运营者能够按官方合同创建 Reporting 任务、完整发现尚未处理的报告，并在报告生成期间看到可调度推进的等待、重试、远端失败或就绪状态。

## Acceptance criteria

- [ ] Reporting provider 使用官方 Google 客户端并按官方合同提交报告名称和报告类型。
- [ ] 报告列表消费所有分页，按生成时间和已处理记录选择全部新报告，而不是只取第一页第一条。
- [ ] 不同报告类型拥有独立 job、任务身份、检查点和规范化数据范围。
- [ ] 已导入状态不会终止 job 的后续检查，新生成的日报仍会被发现。
- [ ] 无可下载报告时进入带下一次重试时间的 `waiting`；可重试失败、远端终止失败和就绪状态互不混淆。
- [ ] 创建、轮询和列表翻页遵守配额预算，并在中断后从已确认状态继续。
- [ ] Reporting 轮询注册为到期任务，构建后 CLI 测试覆盖分页、类型隔离、等待、失败和新日报发现。
